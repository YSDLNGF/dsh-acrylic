============================================================
  dsh-acrylic-light 窗口透明补丁 — 安装说明
============================================================

本文件内容与 GitHub 仓库 README 的「安装」章节一致。
仓库地址: https://github.com/YSDLNGF/dsh-acrylic-light


  ============================================================
   强烈建议使用深色模式（Dark Mode）
  ============================================================

  这套主题对深色模式适配明显更好。浅色模式下壁纸会透出偏亮的
  色调，玻璃面板的层次与文字对比度都不如深色模式清晰。

  为了让效果达到最佳，请把 Harness 切到深色主题：
    设置 -> 通用 -> 外观 -> 深色

  浅色模式也能用，只是观感会打折扣。


------------------------------------------------------------
一、先安装插件（两种方式，二选一）
------------------------------------------------------------

方式一：从插件市场安装（推荐，最简单）

  1. 设置 → 插件市场
  2. 进入「主题」分类
  3. 搜索 dsh-acrylic-light（或「透明亚克力」）
  4. 点击「安装」，按提示重启

方式二：原版方式（从 GitHub 地址添加）

  1. Harness → 插件 → 添加插件
  2. 输入以下地址：

       https://github.com/YSDLNGF/dsh-acrylic-light

     也接受这两种等价写法：

       https://github.com/YSDLNGF/dsh-acrylic-light.git
       github:YSDLNGF/dsh-acrylic-light

     安装后 Harness 会 clone 到
     ~/.dsh/profiles/desktop/node_modules/dsh-acrylic-light，
     登记 bundles，然后提示重启。

  安装完成后：设置 → 通用 → 透明亚克力 → 打开「启用」


------------------------------------------------------------
二、安装补丁（两种方式都需要做这一步）
------------------------------------------------------------

只装插件只改了页面样式，窗口本身仍是不透明的。
这一步让壁纸真正透出来。

  1. 下载补丁包并解压（Releases 里的 dsh-acrylic-light-patch.zip）
  2. 完全退出 DeepSeek Harness
     右下角托盘图标 → 右键 → 退出
     只点窗口右上角的关闭按钮是不够的，程序仍在后台运行
  3. 双击 enable-transparency.cmd

它会自动完成：等待你退出 → 打补丁 → 校验 → 重新启动。
整个过程不需要按任何键。


------------------------------------------------------------
三、注意事项（务必先看）
------------------------------------------------------------

1) 补丁没重启、进度卡住 → 需要先装 Node.js

   如果 Harness 退出后，双击补丁文件没有重启、而且进度卡住不动，
   说明你的电脑上没有 Node.js（补丁工具靠它运行）。

   下载地址: https://nodejs.org

   安装说明：
     - 打开 https://nodejs.org，点击「获取 Node.js」
     - 进入新页面后点击「Windows 安装程序」
     - 下载完成后依次安装（一路默认下一步即可）
     - 安装成功后，退出 PowerShell（终端）页面
     - 重新双击加载补丁程序，等待 Harness 重启

2) 补丁装完后仍然没有透明效果 → 双击 diagnose.cmd

   如果补丁显示成功、Harness 也重启了，但窗口还是不透明，
   请双击补丁包里的 diagnose.cmd 查看诊断。

   它会检查四件事并给出结论：
     - 补丁是否写进 app.asar（有没有 backgroundMaterial）
     - Windows 版本是否支持 Acrylic（需要 Build >= 17134）
     - 系统「透明效果」开关是否打开（设置 → 个性化 → 颜色）
     - 运行环境：虚拟机 / 仅有「基本显示适配器」/ RDP 远程桌面
       这三种情况下系统会主动禁用 Acrylic，补丁再正确也没用

------------------------------------------------------------
五、补丁包里有什么
------------------------------------------------------------

  enable-transparency.cmd   双击入口（推荐用这个）
  apply-when-closed.ps1     脚本主体：等退出→打补丁→校验→重启
  patch-asar.mjs            实际打补丁的工具（等字节修改）
  verify-asar.mjs           校验补丁是否写进归档
  restore-asar.ps1          还原（撤销补丁）
  diagnose.cmd / diagnose.ps1   透明效果诊断
  README-补丁使用说明.md    本说明的 Markdown 版


------------------------------------------------------------
六、卸载与还原
------------------------------------------------------------

只卸载插件（保留窗口补丁）：
  设置 → 插件 → 找到 dsh-acrylic-light → 卸载

连同窗口材质一起还原：
  node uninstall.mjs
  powershell -ExecutionPolicy Bypass -File restore-asar.ps1

两者都做完再重启，恢复原生外观。
